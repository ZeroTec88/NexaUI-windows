Getting Started

Learn how to install NexaUI, configure themes, and build your first modern WinForms application.

Prerequisites: .NET 10 SDK or later, Windows 10/11, Visual Studio 2022 or later (recommended).

Installation

1

Install the NuGet Package

Add NexaUI to your WinForms project using the NuGet Package Manager.

Install-Package NexaUI

Or use the .NET CLI:

dotnet add package NexaUI
2

Update Your Project File

Ensure your project targets Windows and enables WinForms:

<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net10.0-windows</TargetFramework>
    <UseWindowsForms>true</UseWindowsForms>
  </PropertyGroup>
</Project>
3

Apply a Theme

NexaUI includes a built-in theme system. Apply a theme in your application startup:

C#using NexaUI.Themes;

// Apply light theme (default)
ThemeManager.SetTheme(new LightTheme());

// Or apply dark theme
ThemeManager.SetTheme(new DarkTheme());

// Theme changes apply to all controls automatically
ThemeManager.ThemeChanged += (s, e) => {
    Console.WriteLine($"Theme changed to: {e.Current.Name}");
};
VB.NETImports NexaUI.Themes

' Apply light theme (default)
ThemeManager.SetTheme(New LightTheme())

' Or apply dark theme
ThemeManager.SetTheme(New DarkTheme())

' Theme changes apply to all controls automatically
AddHandler ThemeManager.ThemeChanged, Sub(s, e)
    Console.WriteLine($"Theme changed to: {e.Current.Name}")
End Sub
4

Add Controls to Your Form

Drag controls from the toolbox onto your form, or create them programmatically:

C#using NexaUI.Controls;
using NexaUI.Themes;

public partial class MainForm : Form
{
    public MainForm()
    {
        InitializeComponent();
        ThemeManager.SetTheme(new LightTheme());
        BuildUI();
    }

    private void BuildUI()
    {
        var card = new NexaCard
        {
            Title = "Welcome to NexaUI",
            Subtitle = "Modern WinForms controls",
            Dock = DockStyle.Fill
        };

        var button = new NexaButton
        {
            Text = "Get Started",
            Style = NexaButtonStyle.Primary,
            Dock = DockStyle.Top
        };
        button.Click += (s, e) => MessageBox.Show("Hello NexaUI!");

        card.ContentPanel.Controls.Add(button);
        Controls.Add(card);
    }
}
VB.NETImports NexaUI.Controls
Imports NexaUI.Themes

Public Class MainForm
    Public Sub New()
        InitializeComponent()
        ThemeManager.SetTheme(New LightTheme())
        BuildUI()
    End Sub

    Private Sub BuildUI()
        Dim card As New NexaCard With {
            .Title = "Welcome to NexaUI",
            .Subtitle = "Modern WinForms controls",
            .Dock = DockStyle.Fill
        }

        Dim button As New NexaButton With {
            .Text = "Get Started",
            .Style = NexaButtonStyle.Primary,
            .Dock = DockStyle.Top
        }
        AddHandler button.Click, Sub(s, e)
            MessageBox.Show("Hello NexaUI!")
        End Sub

        card.ContentPanel.Controls.Add(button)
        Controls.Add(card)
    End Sub
End Class

Theme Switching at Runtime

Switch themes dynamically without recreating your application:

C#// Toggle between light and dark themes
private void ToggleTheme()
{
    var current = ThemeManager.Current;
    ThemeManager.SetTheme(current is LightTheme ? new DarkTheme() : new LightTheme());
}
VB.NET' Toggle between light and dark themes
Private Sub ToggleTheme()
    Dim current = ThemeManager.Current
    ThemeManager.SetTheme(If(TypeOf current Is LightTheme, New DarkTheme(), New LightTheme()))
End Sub

High DPI Support

NexaUI controls automatically scale for high-DPI displays. Ensure your application is DPI-aware:

<application xmlns="urn:schemas-microsoft-com:asm.v3">
  <windowsSettings>
    <dpiAware xmlns="http://schemas.microsoft.com/SMI/2005/WindowsSettings">true</dpiAware>
    <dpiAwareness xmlns="http://schemas.microsoft.com/SMI/2016/WindowsSettings">PerMonitorV2</dpiAwareness>
  </windowsSettings>
</application>
