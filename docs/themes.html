Themes

NexaUI themes are applied globally through the NexaThemeManager. All controls automatically pick up theme changes without requiring manual style updates.

Built-in Themes

Ocean Dark Default dark theme with blue accents
Frost Light Clean light theme with subtle borders
Obsidian High-contrast dark theme for low-light environments
Sandstone Warm beige theme with amber accents

Setting a Theme

C#NexaThemeManager.ApplyTheme(NexaTheme.OceanDark);
Application.Run(new MainForm());

Custom Themes

Create custom themes by subclassing NexaTheme or by providing a JSON theme file.

C#var custom = new NexaTheme
{
    Name = "MyTheme",
    Background = Color.FromArgb(255, 20, 20, 30),
    Surface = Color.FromArgb(255, 30, 30, 45),
    Primary = Color.FromArgb(255, 99, 102, 241),
    TextPrimary = Color.FromArgb(255, 241, 245, 249),
    TextSecondary = Color.FromArgb(255, 148, 163, 184)
};
NexaThemeManager.RegisterTheme(custom);
NexaThemeManager.ApplyTheme(custom);
Tip: Theme changes are applied immediately to all open forms and controls.
