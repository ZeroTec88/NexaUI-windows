NexaUI Documentation

A complete guide to building modern Windows Forms applications with NexaUI. Theme-aware, designer-friendly, and compatible with both C# and VB.NET.

.NET 10 WinForms C# + VB.NET Theme-Aware Designer-Friendly

Quick Start

Install the NuGet package and start building modern WinForms apps in minutes.

1. Install Package

PowerShellInstall-Package NexaUI

2. Apply Theme

C#using NexaUI.Themes;

// Apply light theme (default)
ThemeManager.SetTheme(new LightTheme());

// Or apply dark theme
ThemeManager.SetTheme(new DarkTheme());
VB.NETImports NexaUI.Themes

' Apply light theme (default)
ThemeManager.SetTheme(New LightTheme())

' Or apply dark theme
ThemeManager.SetTheme(New DarkTheme())

3. Use Controls

C#var button = new NexaButton
{
    Text = "Save",
    Style = NexaButtonStyle.Primary,
    Dock = DockStyle.Top
};
this.Controls.Add(button);
VB.NETDim button As New NexaButton With {
    .Text = "Save",
    .Style = NexaButtonStyle.Primary,
    .Dock = DockStyle.Top
}
Me.Controls.Add(button)

Key Features

🎨 Theme System

All controls respond to ThemeManager.CurrentTheme. Switch between Light and Dark themes at runtime without recreating the application.

🖱️ Native Behavior Preserved

NexaUI controls inherit from native WinForms controls wherever possible. This means keyboard navigation, accessibility, data binding, designer support, and all familiar WinForms behavior continues to work.

🖼️ High DPI Support

All dimensions are stored in device-independent pixels (DIPs) and scaled at runtime. Controls look sharp at 96, 120, 144, and 192 DPI.

♿ Accessibility

Tab navigation, keyboard selection, arrow-key navigation, accessible names, and screen-reader compatibility are preserved from native controls.

🎨 Designer Friendly

Drag controls onto forms, set properties in the Properties window, build, run, save, and reopen the designer. No manual .Designer.cs or .Designer.vb edits required.
