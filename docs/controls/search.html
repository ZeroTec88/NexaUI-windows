SearchBox

A themed search field built on top of NexaTextBox with a search glyph, clear button, and debounced SearchChanged event.

Quick Start

C#var search = new NexaSearchBox
{
    PlaceholderText = "Search students...",
    SearchDelayMs = 250,
    Width = 360
};
search.SearchChanged += (s, e) => RunSearch(search.SearchText);
search.Cleared += (s, e) => ClearResults();
VB.NETDim search = New NexaSearchBox With {
    .PlaceholderText = "Search students...",
    .SearchDelayMs = 250,
    .Width = 360
}
AddHandler search.SearchChanged, Sub(s, e) RunSearch(search.SearchText)
AddHandler search.Cleared, Sub(s, e) ClearResults()

Properties

PropertyTypeDefaultDescription
SearchDelayMsint300Debounce delay in milliseconds
SearchTextstring""Current search text
PlaceholderTextstring""Placeholder text when empty

Events

EventDescription
SearchChangedFires after the debounce delay when text changes
ClearedFires when the user presses Escape or clicks clear
Tip: Use SearchDelayMs to control how often the search fires. A value of 250-300ms is recommended for most use cases.
