Layout

NexaUI provides containers that enhance the standard WinForms layout experience with modern styling and theming support.

NexaPanel

A themed container that inherits from System.Windows.Forms.Panel with optional card styling and shadow.

C#var card = new NexaPanel
{
    Width = 400,
    Padding = new Padding(16),
    CardStyle = NexaCardStyle.Elevated,
    CornerRadius = 8
};
VB.NETDim card = New NexaPanel With {
    .Width = 400,
    .Padding = New Padding(16),
    .CardStyle = NexaCardStyle.Elevated,
    .CornerRadius = 8
}

NexaGroupBox

A themed group box that inherits from System.Windows.Forms.GroupBox.

C#var group = new NexaGroupBox { Text = "Personal Information" };
group.Controls.Add(name);
group.Controls.Add(email);
VB.NETDim group = New NexaGroupBox With {.Text = "Personal Information"}
group.Controls.Add(name)
group.Controls.Add(email)

NexaTabControl

A themed tab control that inherits from System.Windows.Forms.TabControl with modern styling.

C#var tabs = new NexaTabControl { Dock = DockStyle.Fill };
tabs.TabPages.Add("General");
tabs.TabPages.Add("Advanced");
tabs.TabPages.Add("Security");
VB.NETDim tabs = New NexaTabControl With {.Dock = DockStyle.Fill}
tabs.TabPages.Add("General")
tabs.TabPages.Add("Advanced")
tabs.TabPages.Add("Security")

NexaSplitContainer

A themed split container that inherits from System.Windows.Forms.SplitContainer.

C#var split = new NexaSplitContainer
{
    Dock = DockStyle.Fill,
    Orientation = Orientation.Horizontal,
    SplitterDistance = 200
};
VB.NETDim split = New NexaSplitContainer With {
    .Dock = DockStyle.Fill,
    .Orientation = Orientation.Horizontal,
    .SplitterDistance = 200
}
Tip: All layout controls support the standard Controls collection and Dock/Anchor properties.
