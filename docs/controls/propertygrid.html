NexaPropertyGrid

A themed property grid that inherits from System.Windows.Forms.PropertyGrid with modern styling for property categories and editors.

How to Add NexaPropertyGrid Manually

NexaPropertyGrid inherits from System.Windows.Forms.PropertyGrid, so all native property editing, categorization, help, and command area behavior is preserved.

Designer workflow

  1. Build the solution once to load NexaUI controls into the Toolbox.
  2. Drag NexaPropertyGrid from the Toolbox onto your form.
  3. Set Dock, HelpVisible, ToolbarVisible, and PropertySort in the Properties window.
  4. Assign a SelectedObject in code-behind to display its properties.

Creating NexaPropertyGrid in code

C#using NexaUI.Controls;
using NexaUI.Themes;

public partial class SettingsForm : Form
{
    public SettingsForm()
    {
        InitializeComponent();
        ThemeManager.SetTheme(new LightTheme());
        BuildPropertyGrid();
    }

    private void BuildPropertyGrid()
    {
        var propGrid = new NexaPropertyGrid
        {
            Dock = DockStyle.Fill,
            GridStyle = NexaPropertyGridStyle.Default,
            HelpVisible = true,
            ToolbarVisible = true,
            PropertySort = PropertySort.Categorized
        };

        propGrid.SelectedObject = new AppSettings();

        Controls.Add(propGrid);
    }
}
VB.NETImports NexaUI.Controls
Imports NexaUI.Themes

Public Class SettingsForm
    Public Sub New()
        InitializeComponent()
        ThemeManager.SetTheme(New LightTheme())
        BuildPropertyGrid()
    End Sub

    Private Sub BuildPropertyGrid()
        Dim propGrid = New NexaPropertyGrid With {
            .Dock = DockStyle.Fill,
            .GridStyle = NexaPropertyGridStyle.Default,
            .HelpVisible = True,
            .ToolbarVisible = True,
            .PropertySort = PropertySort.Categorized
        }

        propGrid.SelectedObject = New AppSettings()

        Controls.Add(propGrid)
    End Sub
End Class

Features

  • Themed editors: Modern property editors for strings, numbers, colors, and enums
  • Category styling: Enhanced category headers
  • Help pane: Optional description pane for selected properties
  • Custom editors: Support for UITypeEditor-based custom editors
