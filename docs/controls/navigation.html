Navigation

NexaUI navigation controls help users move through content, data, and application views with familiar yet modern patterns.

NexaBreadcrumb

A trail-style navigation control that inherits from System.Windows.Forms.FlowLayoutPanel.

C#var breadcrumb = new NexaBreadcrumb();
breadcrumb.Items.Add("Home");
breadcrumb.Items.Add("Products");
breadcrumb.Items.Add("Software");
breadcrumb.ItemClicked += (s, e) => NavigateTo(e.Item.Text);
VB.NETDim breadcrumb = New NexaBreadcrumb()
breadcrumb.Items.Add("Home")
breadcrumb.Items.Add("Products")
breadcrumb.Items.Add("Software")
AddHandler breadcrumb.ItemClicked, Sub(s, e) NavigateTo(e.Item.Text)

NexaPagination

A paging control for data-heavy screens.

C#var pager = new NexaPagination { TotalItems = 250, PageSize = 20, CurrentPage = 1 };
pager.PageChanged += (s, e) => LoadPage(e.PageIndex);
VB.NETDim pager = New NexaPagination With {.TotalItems = 250, .PageSize = 20, .CurrentPage = 1}
AddHandler pager.PageChanged, Sub(s, e) LoadPage(e.PageIndex)

NexaSidebarNav

A themed sidebar navigation panel.

C#var sidebar = new NexaSidebarNav();
sidebar.Items.Add(new NexaNavItem { Text = "Dashboard", Icon = "dashboard" });
sidebar.Items.Add(new NexaNavItem { Text = "Reports", Icon = "reports" });
sidebar.SelectionChanged += (s, e) => OpenView(e.SelectedItem.Text);
VB.NETDim sidebar = New NexaSidebarNav()
sidebar.Items.Add(New NexaNavItem With {.Text = "Dashboard", .Icon = "dashboard"})
sidebar.Items.Add(New NexaNavItem With {.Text = "Reports", .Icon = "reports"})
AddHandler sidebar.SelectionChanged, Sub(s, e) OpenView(e.SelectedItem.Text)
Tip: All navigation controls support keyboard navigation and proper focus management.
