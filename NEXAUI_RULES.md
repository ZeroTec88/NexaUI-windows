# NexaUI Permanent Rules

These rules apply to every change made to the NexaUI framework.

1. Windows Forms only.
2. Target .NET 10.
3. NexaUI implementation is C#.
4. NexaUI must be consumable from C# and VB.NET.
5. Prefer native WinForms controls over custom implementations.
6. Do not redraw standard controls from scratch unless there is a genuine reason.
7. Preserve native WinForms behavior.
8. Preserve Visual Studio Designer compatibility.
9. Avoid unnecessary third-party dependencies.
10. Do not copy DevExpress source code, assets, or proprietary implementation.
11. NexaUI must have its own visual identity.
12. Every new control must be demonstrated in BOTH demo projects.
13. Every new feature must be tested.
14. Build the solution after every implementation phase.
15. Do not modify unrelated projects unnecessarily.
16. Keep public APIs simple and VB.NET friendly.
17. Do not introduce WPF.
18. Do not introduce XAML.
